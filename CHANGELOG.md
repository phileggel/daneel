# Changelog

What a project must act on when it takes a new version of a plugin.

## flow 0.1.0 — 2026-10-25

The first release. `plan-batch`, `backlog` and `flow-audit`, extracted from folioneer's
and PatientManager's copies; their settings are in `.claude/daneel.json`, one key per
piece, each named in the piece's doc. To take it: enable `flow@daneel`, set the keys,
and drop the project's own copies.

## app 0.1.0 — 2026-10-25

The first release, the addon for folioneer and PatientManager. The reviewers
`spec-reviewer`, `contract-reviewer`, `adr-reviewer`, `spec-checker` and
`reviewer-guides`, with `protocol.md`, `branch.sh` and `review-path.sh`; the skills
`visual-proof` and `dep-audit` — from both projects' copies (90–97% alike). To take it:
enable `app@daneel` beside `flow@daneel`, set `review.*` in `.claude/daneel.json` for
`reviewer-guides`, and drop the project's own copies.
